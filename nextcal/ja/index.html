NextCal

NextCal は、iPhone のカレンダーの「これから始まる予定」を、ロック画面と Dynamic Island の Live Activity に、カウントダウンつきで表示するアプリです。予定を見逃さないための、iPhone 専用の無料アプリです。

できること

  • 予定が近づくと、ロック画面と Dynamic Island に、自動で Live Activity が出て、始まると自動で消えます。毎日アプリを開いたり、ボタンを押したりする必要はありません。
  • 開始時刻ごとに、別の Live Activity で、予定の名前とカウントダウンを表示します。同じ時刻に始まる複数の予定は、まとめて 1 枚に表示します。
  • 通知を許可していれば、アプリを閉じていても、強制終了していても、新しく追加した予定を拾います（通知は目立たない形で送られます）。
  • iPhone のカレンダーアプリに入っているカレンダー（iCloud、Google など）を使います。使うカレンダーと、終日の予定を含めるかを、選べます。
  • （バージョン 1.1 以降・任意）Google カレンダーに、直接つなぐこともできます。読み取りのみで、予定の変更が、すばやく反映されます。つなぐ場合も、予定の内容は、iPhone の外へ送信しません。

プライバシー

予定の内容（名前・場所・参加者・メモ）は、iPhone の外へ送信しません。詳しくは、プライバシーポリシーをご覧ください。
