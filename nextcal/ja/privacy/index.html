プライバシーポリシー

最終更新日：2026年10月31日

minamia-works（以下「当方」）は、iOSアプリケーション「NextCal」（以下「本アプリ」）における情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 要点

  • カレンダーの予定の内容（名前・場所・参加者・メモ）は、端末の外に送信しません。予定の読み取りと表示の判断は、すべて端末の中で行います。
  • ロック画面や Dynamic Island に表示を出すため、当方のサーバーが、通知を送る時刻と、端末の宛先だけを預かります。
  • 広告（Google AdMob）を表示します。
  • Google カレンダーとの連携は、任意です。つなぐ場合も、予定の内容は、端末の外に送信しません。

2. サーバーに送信・保存する情報

本アプリは、アプリが閉じている間も、時刻どおりに Live Activity を出し、消すために、当方のサーバーに次の情報を送り、保存します。

情報内容・目的
端末の識別子と秘密値端末ごとに、アプリが作るランダムな値です（氏名や Apple ID とは結びつきません）。秘密値は、ハッシュ化して保存します。サーバーが、端末を見分け、他の人から操作されないようにするために使います。
通知の宛先（トークン）Apple の通知サービス（APNs）が、この端末に通知を届けるための値です。表示の開始用・更新用など、複数あります。
通知を送る時刻Live Activity を始める・終わらせる・端末を起こす時刻（UNIX 秒）と、表示を見分けるための鍵（予定の開始時刻）です。予定の名前などの内容は含みません。
表示のオン・オフLive Activity を一時停止しているかどうかです。
連絡の記録端末から最後に連絡があった時刻、応答のなかった通知の数、サーバーが送った通知の種類と時刻です。通知の内容は含みません。動作の確認と、案内の通知（開始できなかったとき）のために使います。
Google カレンダーの変更通知の登録（任意の連携を使うときだけ）通知を見分けるための、ランダムな番号と確認用の値と期限です。メールアドレス・Google のトークン・予定の内容は含みません。連携を解除するか、アプリを削除して 90 日たつと、削除します。

収集しない情報

  • 予定の名前・場所・参加者・メモなど、カレンダーの内容
  • 氏名、メールアドレス、電話番号など、個人を特定できる情報
  • 位置情報、連絡先
  • アカウント情報（本アプリはアカウント登録・ログインを必要としません）

3. 情報の利用目的

  • 予定の開始前に、ロック画面・Dynamic Island に Live Activity を表示し、開始後に消すため
  • 表示が出なかったときに、案内の通知を送るため
  • サービスの安定した運営と、不具合の調査のため

4. 保存期間と削除

  • 端末から 90 日間連絡がない場合、サーバーはその端末の情報を自動で削除します。
  • サーバーの情報の削除を希望する場合は、下の連絡先にご連絡ください。端末の識別子（アプリの端末内に保存されるランダムな値）が必要になるため、ご本人の確認ができる範囲で対応します。確認が難しい場合も、アプリを削除したうえで 90 日経てば、自動で削除されます。
  • アプリをアンインストールした場合も、サーバーの情報は、上の 90 日が過ぎると自動で削除されます。

5. 広告

本アプリは、Google LLC の広告サービス「AdMob」を利用して、アプリを開いたときに全画面の広告を表示します。バックグラウンドで更新が行われるとき、および Live Activity の更新では、広告を表示しません。

  • 広告の配信・計測のため、Google が、端末の情報（広告に使う識別子、IP アドレス、広告の操作の記録、端末・アプリの情報など）を収集・利用することがあります。詳しくは、Google のポリシーをご覧ください。
  • EU・英国・米国の一部の州など、法令で必要な地域では、広告に関する同意の確認（Google の UMP）を表示します。同意は、アプリの「設定 → このアプリについて → 広告のプライバシー設定」（表示される地域のみ）から、いつでも変更できます。
  • 本アプリは、Apple の App Tracking Transparency（アプリの追跡の許可）は求めません。

6. 端末の権限

  • カレンダー（フルアクセス）：予定を読み取り、表示を決めるために使います。読み取った内容は、端末の外に送信しません。
  • 通知：アプリを閉じている間に追加・変更された予定を検知するために、静かな通知（画面を点けず、音も出さず、通知センターに残らない通知）を約 5 分おきに受け取ります。この通知で動く拡張機能が、端末の中でカレンダーを読み、予定の開始時刻だけをサーバーに送ります（予定の名前などの内容は送りません）。また、表示を開始できなかったときの案内にも使います。通知を許可しなくても、アプリを開いている間は動作します。
  • Live Activity：ロック画面・Dynamic Island に表示するために使います。

7. Google カレンダーとの連携（任意）

本アプリは、お客様が選んだ場合に限り、お客様の Google アカウントの Google カレンダーを、読み取れます（バージョン 1.1 以降）。つながなくても、本アプリは使えます。

  • 読み取る情報：予定の名前、開始・終了の時刻、終日かどうか、お客様の出欠の返答、カレンダーの名前と色。読み取りのみで、予定の作成・変更・削除はしません。
  • 使い方：これらの情報は、お客様の iPhone の中だけで、ロック画面などに次の予定を表示するために使います。予定の内容と、Google のアクセス用の鍵（トークン）は、当方のサーバーを含め、iPhone の外へ送信しません。
  • 保存：Google のアクセス用の鍵は、お客様の iPhone の Keychain に、この端末の中だけに保存します。通信できないときのために、予定の一時的な写しを、iPhone の中に最大 3 日間保存します（バックアップには含まれません）。
  • 変更の通知：Google カレンダーの予定が変わったことを素早く知るため、Google から、当方のサーバーへ、「変更があった」という通知（予定の内容やメールアドレスを含まない通知）を受け取ることがあります。サーバーが保存するのは、通知を見分けるための、ランダムな番号と確認用の値と期限だけです。
  • 共有・広告：Google から取得した情報を、第三者へ提供せず、広告・分析・販売には使いません。人が読むこともありません。
  • やめるとき：アプリの設定の「Google カレンダー」から、アカウントを解除してください。Google への権限の取り消しと、iPhone の中の鍵・写しの削除を、同時に行います。Google アカウントの設定からも取り消せます。

NextCal's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.（本アプリによる、Google API から受け取った情報の使用と、他のアプリへの転送は、限定的な使用の要件を含む、Google API サービスのユーザーデータに関するポリシーに従います。）

8. 第三者サービス

  • Apple（APNs）：通知の配信
  • Fly.io：サーバーのホスティング（東京リージョン）
  • Google AdMob：広告の配信
  • Google（Google カレンダー API）：任意の連携で、お客様の iPhone が、直接つなぐ（当方のサーバーは通りません）

当方は、上記以外に、情報を第三者へ提供しません。ただし、法令に基づく開示の請求があった場合を除きます。

9. お子様のプライバシー

本アプリは、13歳未満のお子様を対象としたものではなく、お子様から意図的に情報を収集することはありません。

10. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加などに応じて、変更されることがあります。変更後のポリシーは、本ページに掲載した時点から効力を生じます。
